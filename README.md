# 圓周長與直徑關係電腦版

電腦版（橫式大畫面）互動教具。拖曳「直徑」或「圓周長」滑桿改變圓的大小，
按下按鈕後，圓周長會從圓上拉直成一條直線，直徑也會拉到下方，
兩條線並排比較，並用直徑當作尺一段一段量出「3 個直徑再多一點點」。

## 檔案
- `index.html`：主程式（單檔，含全部 CSS / JS）
- `manifest.json`：PWA 設定
- `sw.js`：Service Worker，離線可用
- `icons/`：應用程式圖示

## 使用方式
1. 把整個資料夾放到任何靜態網頁空間（例如 GitHub Pages）。
2. 以 https 開啟 `index.html`，瀏覽器網址列會出現「安裝」圖示，可安裝成桌面應用程式。
3. 直接雙擊開啟本機檔案也能正常使用，只是 Service Worker 不會啟用。
